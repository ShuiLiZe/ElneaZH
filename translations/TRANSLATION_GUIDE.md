# Elnea Kingdom 汉化翻译规范（所有翻译子任务必读）

## 风格
- 用户要求：地道中文本土腔，**带四川调调**，绝不要机翻腔/生硬直译。
- **角色台词/对话/事件剧情/晚餐聊天/课堂/PvP 解说/Tips**：四川味普通话，人人能看懂。适度使用：嘛、噻、哦、哟、嘞、咯、撒、巴适、安逸、要得、莫得/没得、啥子、咋个、晓得、娃儿、耍、搞快点、霸道、恼火、硬是、好凶、背时、遭了、扎起。不要每句堆方言词，一句最多一两个，读起来自然顺口。男女老少语气有区别（man/woman/boy/girl/adult/child 键）。礼仪场合（加冕、葬礼、议会、神官致辞）口吻庄重，方言味收敛。
- **界面/系统文字/菜单/按钮/属性名/成就标题/日程名/地名/人名/物品名**：标准简体中文，简洁，按钮 2–4 字为佳，**不带方言**（成就的 message 可以带一点俏皮川味）。
- 拟声/怪声（如 Kurupyui♪、Fugurupyou…、Gururu…pu…）音译成可爱中文拟声词（咕噜噗咿♪ 之类），保留 ♪★ 符号。
- 中文标点：，。！？……——「」。英文里的 "..." 译作 "……"。

## 必须原样保留
- 变量 `$(xxx)$`、格式符 `{0}` `{1:D}`、换行 `\n`（字面两个字符）。可以调整它们在句中的位置，但数量和拼写不能变。
- 不要输出半角双引号 `"`，需要引号用「」或“”。ZoneHelp 不能出现 `^`。
- `$(You)$` 是玩家名，`$(Act00Name)$` 等是角色名。

## 术语
- 一律以 `work/glossary.json`（英文→中文）为准；遇到表里没有的专有名词，自己定一个译名并追加到你输出的 `newterms` 里。
- 游戏名 Elnea Kingdom = 艾尔尼亚王国。

## 输入 / 输出
- 输入：`work/src/<资源名>.json`  = {uid: 英文}；日文参考在 `work/text_jp/<资源名把_en换成_jp>.txt`（可选看）。
- 输出：`repo/translations/<资源名>.json` = {uid: 中文}，**uid 一个不能少**，UTF-8，ensure_ascii=False。
- 写完用 `python3 work/check_tr.py <资源名>` 自检（占位符、引号、缺失）。
- 每完成几个文件就提交：`python3 work/ghpush.py "Add zh translation: <files>" repo translations/<文件>.json ...`（英文提交信息）。
